# Daily-Journal
This is a template for the research journal taking for the year 2026.

The dates need to be adjusted by the author. You can change the author name in the daily_task.tex document and also the other details. 

I have added only three basic requirements, 
- To-Do List
- Completed (written in explicit manner)
- Notes (Something importnant you want to take the note of.)

Uncomment the weeks accordingly in the respective Months/<month_name.tex>  and then enjoy journaling your everyday research tasks.

Authors are welcomed to edit as per their requirements and do the work accordingly.
